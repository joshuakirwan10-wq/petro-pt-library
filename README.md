# Petro Exercise Library

The Petro Personal Training exercise library: looping demos, cardio sessions with a built in timer, a 5 km run log and a zone 2 heart rate calculator.

Live at https://petro-pt-library.netlify.app. Netlify publishes this folder as it is, no build step.

Updates: Claude pushes changes to the main branch and Netlify publishes them automatically.
